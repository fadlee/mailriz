  <Card title="Karang alamatnya sambil jalan" icon="email">

    `netflix@domainanda.com` di formulir pendaftaran, dan aliasnya muncul saat

  </Card>
  <Card title="Data tetap milik Anda" icon="cloud-download">

  </Card>
  <Card title="Satu perintah untuk deploy" icon="rocket">

    penyimpanan, DNS, dan perutean email.
  </Card>
